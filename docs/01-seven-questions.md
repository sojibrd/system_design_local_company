# ব্লক ১ — সাতটা প্রশ্ন, নিজের প্রজেক্টে

*দিন ০০১–০১৪ · ডক ০৯, ১১–১৫, ১৮ · functional লেভেল*

লোকাল আলোচনায় system design মানে পাঁচ-সাতটা চেনা প্রশ্ন, আর উত্তর আসে **আপনার নিজের প্রজেক্ট** থেকে। এই দুই সপ্তাহে সাতটা ডক — প্রতিটা একটা প্রশ্নের পেছনের ধারণা। পড়ার ক্রম ডকের নম্বরে নয়, প্রশ্নের গুরুত্বে: API → database → cache → ট্রাফিক → queue → CDN → monitoring। 🧠 (Pareto · Chunk the subject)

প্রতিটা ডকের দিনে কাজ একটাই: দরকারি অংশটুকু পড়ে **ডক বন্ধ**, তারপর `srdtube` বা অফিসের কাজ দিয়ে ৫ লাইন। নিজের উদাহরণ না এলে ওটাই আজকের ফাঁক। 🧠 (Active learning)

> **ব্লক শেষে:** সাতটা ডকের প্রতিটায় নিজের প্রজেক্টের একটা উদাহরণ লেখা, আর দুটো simulation-এর functional লেভেল কাগজে আঁকা?

- [ ] ৫′ একজনকে বলুন: *"চার সপ্তাহে srdtube-এর design doc — শেষ দিনে জিজ্ঞেস কোরো"* 🧠 (Stakes & Rewards · Community)

> **দিন শেষে:** ছয় সেকশনের কার্ড আছে, প্রতিটায় srdtube-এর এক লাইন?

> **দিন শেষে:** "cache কোথায়" — তিন জায়গার একটা বাছাই আর কারণ লেখা?
